# Angular 22 stable patch refresh — October 30, 2026

## Scope

This branch upgrades the existing Angular 22 application to the latest confirmed **stable** releases available on October 30, 2026. It does **not** migrate to a new Angular major or adopt any 22.3.0 prerelease.

- Angular framework packages (`@angular/core`, `common`, `compiler`, `forms`, `localize`, `platform-browser`, `router`, `service-worker`, `compiler-cli`, `language-service`): **22.2.3 → 22.2.4**.
- Angular CLI / build tools (`@angular/cli`, `@angular/build`, `@angular-devkit/core`): **22.2.4 → 22.2.5**.
- Keep Angular ESLint dependencies on their existing 22.6.0 line.
- Keep TypeScript constrained to `~6.0.2` (the regenerated lockfile resolves **6.0.3**, which remains within this range).
- Keep Electron 44, Ledger transports, wallet encryption, server/RPC defaults, PoW engines and PWA service-worker behavior unchanged.
- Keep `package-lock.json` reproducible with lockfile v2, generated by npm on Node.js 24.15.0 with `--legacy-peer-deps --ignore-scripts` and verified against the declared Angular package versions.

## Official sources and runtime compatibility

- Angular framework 22.2.4: https://github.com/angular/angular/releases/tag/22.2.4
- Angular CLI 22.2.5: https://github.com/angular/angular-cli/releases/tag/v22.2.5
- Supported runtime versions: https://angular.dev/reference/versions
- Angular 22.0 compatibility: Node.js `^22.22.3 || ^24.15.0 || ^26.0.0`, TypeScript `>=6.0.0 <6.1.0`, RxJS `^6.5.3 || ^7.4.0`. Follow the official compatibility reference if later minor versions change these requirements.

## Regression and security gates

Before considering a merge, require:

1. All required GitHub checks green: Angular 22 validation, Merge Gate, CodeQL Advanced v4, lint, dependency/security audits and Electron Linux/Windows/macOS packages.
2. Reproducible `npm ci --legacy-peer-deps` using the committed lockfile; `npm run lint`; Jasmine/Karma unit and RPC regression suites.
3. Production browser/Web/PWA build, Playwright startup smoke tests, offline launch then connectivity restoration, service-worker update, wallet-balance refresh and local browser PoW.
4. Hardware smoke tests, when feasible: Ledger Nano S Plus USB and Nano X USB/Bluetooth; cancel/reconnect flows; an existing wallet receive/send and representative change. Do not sign with or expose any real recovery seed in diagnostics.
5. No unrequested deployment to Apache, Vercel or GitHub Pages. No automatic merge into `master`; complete code/security review and obtain explicit approval.

## Rollback and review guidance

Changes are isolated to this maintenance branch and should be reversible by returning to the previous `master` commit and its lockfile. Patch releases contain compiler/compiler-cli and build-tool changes that can alter template compilation, translation handling, Vite asset processing and service-worker cache contents. Review these especially carefully for Nault's Ledger-related UI, RPC fallback logic, PoW workers and installed PWA.
