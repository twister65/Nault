# Nault 1.19.7 — twister65 fork

This is a release of the independently maintained [twister65/Nault](https://github.com/twister65/Nault) fork, not an official upstream Nault/Nault release.

## Highlights since v1.19.6

- **Electron 45.5.0 ([#122](https://github.com/twister65/Nault/pull/122)).** Update the desktop runtime from 45.4.1 to 45.5.0, with synchronized npm v2 lockfile, unchanged direct dependency ranges, and updated security and compatibility assertions. Existing dependency overrides and sandbox/IPC policies are retained. [Official Electron release notes](https://releases.electronjs.org/release/v45.5.0).
- **Native macOS distribution retired ([#121](https://github.com/twister65/Nault/pull/121)).** No new macOS Intel or Apple Silicon DMG, ZIP, or updater assets are published. The supported alternative is the [installable Nault PWA in Google Chrome](https://twister32.changeip.org/). Historical releases and native macOS source/configuration remain available; this does not imply support for those native builds.
- **Release integrity preserved.** Windows and Linux updater metadata, SHA-256 checksums, native artifact provenance attestations and install/remove smoke tests remain mandatory. Release assembly and provenance checks reject retired macOS artifacts.

## Downloads (after publication)

- Windows x64: NSIS EXE.
- Linux x64: AppImage (portable), DEB (Debian/Ubuntu/Mint), RPM (Fedora/openSUSE), Pacman (Arch/Manjaro).
- macOS: Chrome PWA only for this release. Ledger USB and Bluetooth were tested with the PWA on Intel macOS Sequoia; Apple Silicon was not tested.
- Browser/PWA: install from the hosted wallet once the separate production deployment has been approved and performed.

## Validation and limitations

- The Electron migration PR passed Angular 22 validation, regression tests and desktop build, audit, CodeQL, Merge gate, Windows/Linux packaging, release preview, and installation/removal checks for Ubuntu, Debian, Fedora, openSUSE and Arch.
- Physical Ledger USB and Bluetooth connections were tested successfully by the maintainer. On Linux, establishing the Bluetooth connection required `bluetoothctl`; subsequent GATT/MTU negotiation, address reads and reconnections succeeded. This remains a known operational limitation, not a claimed transport fix.
- The test logs also show WebSocket confirmations, remote PoW generation and Nano send/receive activity.
- Windows browser/PWA WebAuthn PRF device unlock remains disabled pending a verified fix. No native macOS signing/notarization or Apple Silicon hardware validation is claimed.
- The version-only release preparation PR requires its own CI validation. Tagged builds and updater artifacts must be checked before relying on the published release.

## Release procedure

1. Merge the release preparation PR after CI passes.
2. Confirm all three version fields equal 1.19.7 and Electron is pinned to 45.5.0.
3. Create and push the annotated `v1.19.7` tag on the validated master commit only after release approval. The tag triggers Electron App Release, which automatically publishes after packaging, installation tests, checksum and provenance gates pass.
4. Verify the five native binaries (Windows EXE and four Linux packages), updater metadata, checksums and attestations; ensure no macOS artifacts are present.
5. Deploy the PWA separately on the production host using the release-aware deployment script and retain the previous release for rollback. Confirm About Nault, Service Worker, TLS, RPC/WebSocket and PoW.
