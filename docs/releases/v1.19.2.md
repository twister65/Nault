# Nault 1.19.2 — twister65 fork

This is a release of the independently maintained [twister65/Nault](https://github.com/twister65/Nault) fork, not an official upstream Nault/Nault release.

## Highlights since v1.19.1

- **Electron 44.11.2 ([#94](https://github.com/twister65/Nault/pull/94)).** Updates Electron 44.10.1 → 44.11.2 and authentic npm lockfile integrity, including corresponding security regression and CI version guards. Electron 45 is not included.
- **Fork-specific welcome links ([#95](https://github.com/twister65/Nault/pull/95)).** The first-run welcome page now points to this fork's repository, releases and hosted web wallet, with updated English, French, German and Spanish wording.
- **Acknowledgements ([#98](https://github.com/twister65/Nault/pull/98)).** Credits Nano.to, NanoNode.de and NanoTicker in the README.
- **Native Apple Silicon packages targeted again.** Unlike v1.19.1, which shipped macOS Intel only, v1.19.2 is prepared to include macOS Apple Silicon (arm64) **DMG and ZIP** packages alongside Intel (x64), subject to successful `macos-15` CI builds and artifact verification.

## Downloads by platform (available only after successful release publication)

- **Windows:** 64-bit installer (EXE).
- **macOS Intel (x64):** DMG and technical ZIP for updates.
- **macOS Apple Silicon (arm64):** DMG and technical ZIP for updates — **mandatory for this release**, not yet verified until the `macos-15` job passes.
- **Linux x64:** Debian/Ubuntu/Linux Mint (DEB), Fedora/openSUSE (RPM), Arch/Manjaro (Pacman), and portable AppImage.
- Update metadata (`latest*.yml`), blockmaps and SHA-256 checksums are produced by the release workflow and verified before publication.

## Installation testing and limitations

**Manual installation testing reported to date is limited to the Windows installer, the Linux Ubuntu DEB package and the portable Linux AppImage.** This reflects previously tested packages; it is **not a claim that the new v1.19.2 binaries have already been installed or manually tested**.

- macOS Intel and Apple Silicon installation, RPM and Pacman installation, and other Linux distributions have **not** been manually validated.
- Automated CI build / package checks and isolated Linux package installation-removal tests, where successful, are separate from real-device/manual installation tests.
- No macOS code signing or notarization is implied by successful unsigned CI packaging. macOS ZIP updater behavior may require signed builds.
- Real Ledger Nano S Plus (USB/WebHID) and Nano X (USB/Web Bluetooth) functional smoke tests have **not** been performed on the new v1.19.2 artifacts. Successful automated Ledger transport tests do not replace physical-device validation.

## Release process: Apple Silicon required

**Preparation does not publish the release.** After this version-bump PR is merged and its CI is satisfactory, create and push the **`v1.19.2`** tag at the intended `master` commit. All three versions (`package.json`, lockfile root, lockfile package root) must be `1.19.2`.

The tag triggers the [Electron App Release](https://github.com/twister65/Nault/actions/workflows/electron_hash.yml) workflow. Its matrix includes `macos-15` (Apple Silicon) and `macos-15-intel` (Intel), as well as Windows and Ubuntu. The publication stage checks for **two macOS DMGs, two macOS ZIPs**, the combined `latest-mac.yml`, and all Linux / Windows artifacts. A missing arm64 package must block publication, **not silently fall back to an Intel-only release**.

If the `macos-15` build fails or cannot get a runner on November 12, 2026, **leave the release unpublished**. On November 13, 2026 (morning, Europe/Paris), inspect the failure and re-run the failed GitHub Actions job(s). Do not force publishing or remove the Apple Silicon requirement. The retry is a manual follow-up, not an already scheduled action.

## Apache PWA deployment

GitHub Desktop release publication does not deploy the Apache-hosted PWA. After publishing and checking the release, deploy the verified tag manually:

```bash
~/bin/deploy-nault-master.sh --tag v1.19.2
```

Check the version and exact revision in the Desktop and PWA About pages, balances, representatives, and Ledger connectivity; preserve the previous Apache version for rollback.
