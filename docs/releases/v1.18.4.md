# Nault 1.18.4 — twister65 fork

This is an independently maintained release of **[twister65/Nault](https://github.com/twister65/Nault)**, not an official release from [Nault/Nault](https://github.com/Nault/Nault).

## Highlights

- **Angular 22** migration of the web wallet and PWA, retaining Karma/Jasmine tests and improving responsive layouts on Android tablets ([#25](https://github.com/twister65/Nault/pull/25)).
- **Electron 44.10.0** desktop runtime for Linux, Windows and macOS, with protected IPC and updated native build dependencies ([#35](https://github.com/twister65/Nault/pull/35)).
- **Ledger Nano S Plus over USB/WebHID** and **Nano X over USB or Web Bluetooth**, with guarded account identity checks, reconnection, transport selection, and user-denied signing handling ([#25](https://github.com/twister65/Nault/pull/25), [#36](https://github.com/twister65/Nault/pull/36)).
- **S-01 software-wallet protection:** authenticated AES-256-GCM backups with a versioned `nault:v2:` envelope, PBKDF2-HMAC-SHA256 (600,000 iterations), a random salt and nonce, and a minimum 12-character password for new encryption. Historical CryptoJS/OpenSSL v1 backups remain recoverable with their original password. Migration to v2 occurs **only after an explicitly confirmed password change** ([#34](https://github.com/twister65/Nault/pull/34)).
- **Safer backup recovery:** v2 QR links use the compatible HTTPS origin of the running web wallet; JSON export remains available on desktop/local builds. The fork's self-hosted web/PWA location is [twister32.changeip.org](https://twister32.changeip.org/) ([#34](https://github.com/twister65/Nault/pull/34), [#37](https://github.com/twister65/Nault/pull/37)).
- **Dependency and update security:** migrate `electron-updater` to 6.8.12 and patch high-severity dependencies including `semver`, `tar-fs`, `lodash`, `ws`, and development tooling ([#28](https://github.com/twister65/Nault/pull/28)–[#33](https://github.com/twister65/Nault/pull/33)).
- **RPC, PoW and PWA fixes:** continued Nano/RsNano JSON-block support, selected-server PoW, WebSocket/pending balance refresh and offline/reconnection fixes.

## Wallet backup compatibility

Existing encrypted **v1** wallet files are not silently rewritten when opened. Keep an independently verified seed or offline backup before changing a password. The previous v1 export remains readable with its *old* password, while new v2 backups require the *new* password. A QR code or URL is an encrypted backup container, **not a substitute for a separately verified offline recovery copy**.

**Security scope:** encryption protects software-wallet secrets *at rest*; it cannot prevent theft by malicious browser extensions, XSS running in the wallet origin, a keylogger, or malware on an unlocked computer. Ledger seeds are not affected.

## Validation and limits

- Automated: Angular 22 build and unit tests, RPC/regression checks, CodeQL Advanced, dependency audit, Electron packaging on supported runners.
- Manual: ChromeOS software wallet creation (S01-01, 6/6), lock/unlock and persistence (S01-02, 6/6), and historic v1 → v2 migration with unchanged Nano account addresses and v1 rollback (S01-04, 7/7). Ledger USB/Bluetooth and Android PWA functional paths were previously tested; **the S-01 historic migration was not retested on Android**.
- macOS hardware pairing and Ledger signing were not validated on a physical Mac. CI packaging does not replace real-device testing.
- Desktop installers in this fork are **unsigned** and macOS builds are **not notarized**. Do not confuse them with official upstream binaries.

## Downloads and checksums

GitHub Actions published this release from the verified `v1.18.4` tag after all three desktop packages and their checksums passed validation. Download Linux AppImage, Windows installer, or macOS Intel DMG from this release's **Assets**. Validate downloaded files against the attached `SHA256SUMS`, calculated from the exact uploaded binaries.

Linux: `sha256sum Nault-1.18.4.AppImage`

Windows (PowerShell): `Get-FileHash -Algorithm SHA256 '.\\Nault.Setup.1.18.4.exe'`

macOS: `shasum -a 256 Nault-1.18.4.dmg`

Compare the printed hash to the matching line in `SHA256SUMS`. The three installers, update metadata, and `SHA256SUMS` are attached to the published release.
