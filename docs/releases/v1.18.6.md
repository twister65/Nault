# Nault 1.18.6 — twister65 fork

This release is independently maintained by [twister65/Nault](https://github.com/twister65/Nault); it is **not** an official release of [Nault/Nault](https://github.com/Nault/Nault).

## What's new since 1.18.5

- **Angular maintenance:** update the Angular framework to **22.2.4** and CLI/build tooling to **22.2.5**, retaining the existing validated Ledger, RPC, PoW and PWA workflows ([#55](https://github.com/twister65/Nault/pull/55)).
- **Unified release identification:** show the Nault version and the exact source Git commit in **About Nault** on both the hosted PWA and Electron desktop application. Both values are embedded at build time, with localized labels in English, French and Spanish ([#56](https://github.com/twister65/Nault/pull/56)).
- **Simplified navigation:** place **About Nault** at the former **Advanced Tools** position in the main menu and temporarily hide **Advanced Options** in Account Details. The underlying advanced feature code remains available for future development ([#56](https://github.com/twister65/Nault/pull/56)).
- **Security pipeline reliability:** retry the verification of published CodeQL categories during GitHub's asynchronous SARIF indexing. Missing categories and open alerts still block the merge gate ([#56](https://github.com/twister65/Nault/pull/56)).
- **Desktop and documentation maintenance:** remove the upstream Discord entry from the desktop Help menu ([#49](https://github.com/twister65/Nault/pull/49)); update the README and S-01 security review ([#54](https://github.com/twister65/Nault/pull/54)). The final v1.18.5 Windows NSIS metadata fixes are carried forward.

## Validation and security

- The user confirmed **14/14** PWA functional checks, including account details, mobile navigation, localization, and the version/commit link, and confirmed the Electron Ubuntu functional test.
- CI verification for this release must include Angular 22, Karma/Jasmine, RPC, security dependency checks, CodeQL v4, lint, and desktop packaging.
- The immutable release tag `v1.18.6` must reference the exact commit used to package desktop applications and build the Apache-hosted PWA. The version alone is not a substitute for checking the SHA.
- No Ledger seed or private-key data should be included in logs, screenshots or bug reports.

## Desktop downloads and installation

Packages are generated for **Linux AppImage**, **Windows NSIS** and **macOS Intel DMG** by the tag-triggered GitHub Actions workflow. Compare each download with the provided `SHA256SUMS` before installation.

- **Linux:** for updater testing, run a real AppImage, and keep a backup of the previously installed file.
- **Windows:** NSIS binaries are unsigned; operating-system warnings may apply. Verify the checksum and use an isolated test environment.
- **macOS:** the Intel DMG is unsigned and not notarized. Manual installation is required; automatic updates require signing. No Apple Silicon package is claimed in this release.

## PWA deployment

Build the **same tagged commit** on the Apache server via `~/bin/deploy-nault-master.sh --tag v1.18.6` (after checking out the script installed on the server). Confirm that **About Nault** on the production origin shows **1.18.6** and the identical full commit as the desktop builds. Retain the previous release for rollback. No Apache, TLS, ModSecurity, RPC, WS or PoW configuration changes are required.
