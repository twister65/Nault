# Nault 1.19.4 — twister65 fork

This release belongs to the independently maintained [twister65/Nault](https://github.com/twister65/Nault) fork and is not an official Nault/Nault release.

## Highlights since v1.19.3

- **Electron 45.3.2 ([#105](https://github.com/twister65/Nault/pull/105)).** Updates Electron Desktop from **45.3.1 to 45.3.2**, retaining the validated IPC/preload, HID and Ledger Bluetooth integrations. The maintainer successfully tested a physical Ledger Nano S on Linux and a Nano X (Bluetooth and USB) on Windows, including send, receive, explicit rejection, and reconnection.
- **Angular 22.2.6 and Angular CLI/Build 22.2.7 ([#106](https://github.com/twister65/Nault/pull/106)).** Updates Angular framework/compiler from **22.2.4 to 22.2.6**, and CLI/Build from **22.2.5 to 22.2.7**, including locked native Rolldown and Oxc dependencies. CI, unit/regression tests and a Windows Edge PWA with a Ledger Nano X were validated. WebSocket resumed after Ethernet loss and retained the chosen RsNano RPC and Nano.to PoW settings. Android/ChromeOS real-device retests for this specific Angular patch are not claimed.
- **Temporarily disable Windows browser/PWA device unlock ([#109](https://github.com/twister65/Nault/pull/109)).** Windows Hello WebAuthn PRF `GetAssertion` failures (Windows event 1025, `0x8009000B`) were observed despite successful initial enrollment. The optional quick-unlock control is now suppressed in Windows browser/PWA contexts, while preserving the password fallback and existing encrypted enrollment records. Android, ChromeOS, Linux and macOS web capability detection remains unchanged; native Electron Desktop unlock was already out of scope.
- **Verifiable release build provenance ([#103](https://github.com/twister65/Nault/pull/103)).** On tag-triggered releases, nine native desktop binaries are attested on their build runners using GitHub/Sigstore/SLSA provenance. Release assembly and publication independently verify the exact tag and source commit; missing or invalid attestations block publication. This adds provenance verification in addition to SHA-256 checksums; it is not app signing/notarization.
- **Account-management interface and translations ([#104](https://github.com/twister65/Nault/pull/104), [#108](https://github.com/twister65/Nault/pull/108)).** Harmonizes account-management buttons with the Send Nano style, improves the show/hide/manage flows and their FR/EN/DE/ES labels.
- **PWA pending-receive notification access ([#102](https://github.com/twister65/Nault/pull/102)).** Provides an accessible action to unlock the wallet from pending-receive notices when appropriate.
- **Linux compatibility documentation ([#107](https://github.com/twister65/Nault/pull/107)).** Records existing manual Linux package tests from v1.19.3; these are not new v1.19.4 release-artifact tests.

## Downloads (after the release tag is pushed and all gates pass)

- **Windows x64:** NSIS EXE installer.
- **macOS Intel x64:** DMG and technical update ZIP.
- **macOS Apple Silicon arm64:** DMG and technical update ZIP; **do not omit the arm64 build** if its runner is temporarily busy.
- **Linux x64:** portable AppImage, DEB (Ubuntu/Debian/Mint), RPM (Fedora/openSUSE) and Pacman (Arch/Manjaro).
- Electron updater manifests, blockmaps, SHA-256 checksums and verified build attestations are generated by the release workflow.

## Validation scope and known limitations

- **CI before #106 merge:** Angular 22 validation, lint, regression/security checks and Merge gate passed against the branch synchronized with #109. Platform packaging and optional macOS Bluetooth smoke builds must be checked separately in the final release pipeline.
- **Electron 45.3.2 manual checks:** Linux Desktop with Ledger Nano S and Windows Desktop with Nano X USB/Bluetooth passed in the #105 validation campaign.
- **Angular 22.2.6 / Windows PWA:** the maintainer tested Nano X BLE, 1 XNO send/receive, rejected signing, RPC/WebSocket offline-online recovery, Nano.to PoW, and representatives. TinyFish verified no-wallet UI navigation and route rendering.
- **Windows browser/PWA WebAuthn PRF:** deliberately disabled pending an upstream Windows Hello compatibility fix; password unlock remains the supported path.
- **Not claimed as validated on final v1.19.4 artifacts:** Windows/Linux fresh installer installation and physical Ledger operations after tagging; macOS Intel/Apple Silicon physical-device tests; Android/ChromeOS PWA real-device retests on this exact Angular patch; every service-worker upgrade scenario. Packaging CI cannot replace manual hardware tests. macOS packages are not claimed to be signed or notarized.

## Release and publication procedure

Preparing these notes does **not** create a tag, release or production deployment. After the release preparation is merged into `master` and the exact commit is validated, the maintainer may explicitly approve pushing annotated tag **`v1.19.4`** pointing to that commit.

The tag workflow requires these three versions to be `1.19.4`:
- `package.json.version`
- `package-lock.json.version`
- `package-lock.json.packages[""].version`

**Important:** the `v*` tag triggers [Electron App Release](https://github.com/twister65/Nault/actions/workflows/electron_hash.yml). After all Windows, macOS Intel/Apple Silicon and Linux artifacts, Linux install/remove checks, hashes and nine provenance attestations pass, that workflow **automatically publishes** the GitHub release. It is not a draft-only trigger; do not push the tag before approval.

### Apache-hosted PWA

GitHub release publication does not deploy the Apache PWA. When ready to update the production PWA separately:

```bash
~/bin/deploy-nault-master.sh --tag v1.19.4
```

Confirm the **version and embedded commit** in About Nault, Ledger USB/BLE, balances and representatives, RPC/WebSocket, PoW fallback and PWA service-worker update. Retain the previous Apache release for rollback.
