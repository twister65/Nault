# Nault 1.18.8 — twister65 fork

This is an independently maintained release of **[twister65/Nault](https://github.com/twister65/Nault)**, not an official release from [Nault/Nault](https://github.com/Nault/Nault).

## Changes since 1.18.7

- **Electron 44.10.1 security and maintenance update:** upgrade from 44.10.0 to the 44.10.1 maintenance release, with the matching npm integrity-checked lockfile and updated dependency-security assertions. Angular 22 and Electron Builder remain on their established versions ([#69](https://github.com/twister65/Nault/pull/69); [Electron v44.10.1 release](https://github.com/electron/electron/releases/tag/v44.10.1)).
- **Correct Ledger USB/Bluetooth reconnect choices in Electron:** identify the *selected* Ledger HID interface using its vendor-checked USB product descriptor, forward a strictly allowlisted hardware model through the existing worker/main/renderer boundary, and save the model only after verifying the wallet account. Nano S / S Plus are USB-only, while Nano X retains USB and Bluetooth choices. The user validated Nano S Plus on Linux and confirmed Nano X still offers both reconnect transports; Nano S physical testing remains outstanding ([#70](https://github.com/twister65/Nault/pull/70)).
- **PWA navigation resilience:** use cache-first Angular service-worker navigation for the app shell instead of unnecessary network navigation requests, while preserving freshness policies for external CoinGecko and mynano.ninja data. This is not a change to on-chain receive processing, RPC, or PoW ([#66](https://github.com/twister65/Nault/pull/66)).
- **Tablet CSS loading:** link the global stylesheet directly in the production PWA rather than relying on deferred critical-CSS media switching; retain minification, hashed assets, and existing security headers. No Electron stylesheet or Apache CSP change ([#68](https://github.com/twister65/Nault/pull/68)).

## Scope, validation, and limitations

- Release source: the reviewed release-preparation PR merged into `master`; `package.json.version`, `package-lock.json.version` and `package-lock.json.packages[""].version` must all equal **1.18.8** at the exact release tag.
- The release candidate must pass the Merge gate, Angular 22 build/tests, Electron packaging, CodeQL/dependency security, Ledger USB/BLE regression checks, RPC tests, lint and PWA service-worker/CSS tests before tagging.
- **Not included:** [#71](https://github.com/twister65/Nault/pull/71) (PWA/Desktop parity work, pending separate validation); Ledger Nano Gen5, Flex, Stax and Atom support; and a Linux BlueZ/TP-Link Bluetooth driver fix. A successful Windows BLE reconnect does not prove that the separate Linux radio/MTU problem has been fixed.
- Do not automatically retry Ledger signatures or submit Nano blocks, alter wallets or recovery data, or change RPC/WS/PoW endpoints or Apache/ModSecurity configuration.
- Before deployment, recheck the PWA on Android tablet (CSS, reload, online/offline and navigation) and the Nano S Plus USB and Nano X USB/Bluetooth reconnect choices on Desktop. Do not infer hardware validation for untested models.

## GitHub Desktop release

**Preparation is not publication.** Once the version-bump PR has been merged, create `v1.18.8` **only after explicit approval and the final release gate**. The tag-triggered GitHub Actions workflow checks tag/package/lockfile consistency, then packages Linux **AppImage**, Windows **NSIS installer** and macOS **Intel DMG** from that single immutable tag. It creates/updates a draft GitHub release and automatically publishes it after all three artifacts are present and `SHA256SUMS` validation succeeds.

Verify the workflow results, filenames, checksums and automatic-update metadata before installing. Windows and macOS packages may be unsigned or unnotarized; **Apple Silicon arm64 is not claimed** by this workflow.

## Apache-hosted PWA — manual deployment after publication

Once the `v1.18.8` tag and desktop binaries are validated, deploy the **same tag** to the Ubuntu-Salon Apache host:

```bash
~/bin/deploy-nault-master.sh --tag v1.18.8
```

Confirm that **About Nault** in the PWA at https://twister32.changeip.org/ and the desktop applications shows **Version 1.18.8** and the **same full Git commit SHA**. Allow the PWA service worker to update normally, verify tablet styling and navigation, and retain the prior release for rollback. Do not deploy automatically from this preparation PR.
