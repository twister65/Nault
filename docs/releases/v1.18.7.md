# Nault 1.18.7 — twister65 fork

This is an independently maintained release of **[twister65/Nault](https://github.com/twister65/Nault)**, not an official release from [Nault/Nault](https://github.com/Nault/Nault).

## Changes since 1.18.6

- **Ledger Nano X Bluetooth signing reliability:** prevent periodic Ledger status polling from competing with cache/sign APDUs during sends, receives, representative changes and offline signatures. Categorize user rejection, busy transport and Nano app unavailability; add EN/FR/ES notifications and regression coverage. Never automatically retry a signature or submit a transaction ([#64](https://github.com/twister65/Nault/pull/64), fixes [#58](https://github.com/twister65/Nault/issues/58)).
- **Ledger WebUSB connection reliability:** serialize opening a browser USB session after the previous transport closes, preventing stale-session and reconnect races ([#61](https://github.com/twister65/Nault/pull/61)).
- **Nano RPC compatibility:** remove Berry Pay from the default public-node rotation because of incompatible RPC behavior. Existing Twister32 RsNano RPC, WS and PoW settings remain unchanged ([#60](https://github.com/twister65/Nault/pull/60)).
- **Usability and attribution:** simplify the sidebar while preserving the upstream Nault attribution and link ([#59](https://github.com/twister65/Nault/pull/59), [#62](https://github.com/twister65/Nault/pull/62)); improve balance-card contrast, message readability and light-mode consistency ([#63](https://github.com/twister65/Nault/pull/63)).
- **Build identity in About Nault:** distinguish PWA from desktop, and display the PWA's host/domain alongside release version and embedded Git commit ([#65](https://github.com/twister65/Nault/pull/65)).

## Scope and validation

- Based on the validated `master` branch with Angular 22 and Electron 44.10.0. This release changes the application version to `1.18.7` in both `package.json` and the root entries of `package-lock.json`, without updating dependencies.
- The user reported successful Android Chrome PWA / Ledger Nano X Bluetooth sending following #64. The CI gate includes Angular builds and regression tests, dependency audit, CodeQL and desktop packaging.
- **Not included:** [#66](https://github.com/twister65/Nault/pull/66), the experimental cache-first service-worker navigation change. The intermittent initial navigation request / synthetic 504 investigation remains open.
- No automatic resubmission of financial transactions, and no changes to node credentials, recovery seeds, RPC endpoints or Apache server configuration.
- Always verify the final release tag, checksums and GitHub Actions results before installing the desktop packages or deploying the PWA.

## Desktop distribution

The GitHub Actions workflow triggered by tag `v1.18.7` builds Linux AppImage, Windows NSIS installer and macOS Intel DMG from **the same immutable tagged commit**. Check `SHA256SUMS` before installation. Unsigned Windows and macOS builds may trigger OS security warnings; macOS notarization is not provided. An Apple Silicon package is not claimed.

## Apache-hosted PWA

On the Ubuntu-Salon server, deploy the exact release tag (after it has been created and its CI has passed):

```bash
~/bin/deploy-nault-master.sh --tag v1.18.7
```

Verify that the production PWA at https://twister32.changeip.org/ and the matching desktop builds both display version **1.18.7** and the **same Git commit** in **About Nault**. Allow an existing service worker to update, and retain the prior Apache release for rollback. Do not deploy [#66](https://github.com/twister65/Nault/pull/66) as part of this release.
